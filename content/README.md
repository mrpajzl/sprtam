# Učivo

Všechno učivo Šprtám jako JSON: `topics/<ročník>/<předmět>/` (témata a jejich pořadí v `_subject.json`), `vocab/` (anglická slovíčka), `schema/` (JSON Schema pro editory, generované).

- Jak psát a přidávat obsah: [docs/CONTENT.md](../docs/CONTENT.md)
- Reference polí: [docs/FORMAT.md](../docs/FORMAT.md), widgety: [docs/WIDGETY.md](../docs/WIDGETY.md), galerie: [sprtam.cz/widgety](https://sprtam.cz/widgety)
- Kontrola: `npm run check:content`
